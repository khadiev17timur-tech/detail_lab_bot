# Фото для портфолио

Положите сюда **свои** фотографии работ. Бот подхватит их автоматически по имени файла:

| Карточка                       | Имя файла (любое расширение .jpg .jpeg .png .webp) |
|--------------------------------|-----------------------------------------------------|
| Полировка кузова               | `polish.jpg`                                        |
| Керамическое покрытие          | `ceramic.jpg`                                       |
| Химчистка салона               | `interior.jpg`                                      |
| Защитная плёнка                | `ppf.jpg`                                           |
| Комплексный уход за автомобилем| `complex.jpg`                                       |

Нет файла — бот показывает текстовую карточку, ошибок не будет.
Используйте только фото, на которые у вас есть права. Содержимое этой папки не попадает в git (см. `.gitignore`).
